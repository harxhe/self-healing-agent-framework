# Demo Media

The five PNGs are 16:9 rendered presentation captures for the scripted D1-D5
phases. They are static phase illustrations; the interactive experience is the
Streamlit app at `dashboard/app.py`.

`healagent-demo-walkthrough.mp4` is a silent four-minute backup slideshow made
from those five captures. Rebuild it with:

```bash
python -m report.build_demo_video
```
